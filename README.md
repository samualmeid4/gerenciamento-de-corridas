# 🏎️ Sistema de Gerenciamento de Corridas

Aplicação web desenvolvida em **Python** e **Django** voltada para o gerenciamento de eventos de automobilismo, cadastro de pilotos, equipes, circuitos e apuração de resultados de corridas.

---

## 🎯 Funcionalidades
* Cadastro e gestão de pilotos, equipes e veículos.
* Registro de circuitos e etapas de campeonato.
* Apuração de voltas rápidas e classificação final.
* Consultas relacionais avançadas com Django ORM.

---

## 🛠️ Tecnologias
* **Python**
* **Django**
* **SQLite**

---

## 🚀 Como Executar
```bash
git clone https://github.com/samualmeid4/gerenciamento-de-corridas.git
cd gerenciamento-de-corridas

python manage.py migrate
python manage.py runserver
```
